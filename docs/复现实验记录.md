## 5　拆解五种初始化

令 m=d_out，n=d_in，r=8，α=16，γ=16，c=m^(1/4)/√γ。下表 N 中第二个参数表示方差。所有非零分支均在冻结原层前执行一次 W′=W−sB₀A₀，之后前向为 W′+sBA。

| 方法 / 命令值 | A₀ | B₀ | 前向 s | 校准 |
|---|---|---|---|---|
| 普通 LoRA / lora | Kaiming uniform(a=√5) | 0 | 2 | 无 |
| Gaussian / gaussian | N(0,1/m) | N(0,1/n) | 2 | 无 |
| +SO / so | c·N(0,1/m) | c·N(0,1/n) | 16/√8 | 无 |
| +GA / ga_only | 前 8 个右方向的转置 | 第 9–16 个左方向 | 2 | 前八条 |
| 完整 GA / ga | c·前 8 个右方向的转置 | c·第 9–16 个左方向 | 16/√8 | 前八条 |

普通 LoRA 采用作者代码的均匀边界 ±1/√n；表 3 印出的边界为 ±√(3/n)。Gaussian 对非方形层采用表 3 的 A 方差 1/m、B 方差 1/n；作者 gaussian.yaml 选择 unit 初始化，reinit_lora_modules 的代码实际使用 A 方差 1/n、B 方差 1/m。作者 simple/stable 分支还引用了该分支未赋值的 m、n。本项目直接从原权重 shape 解析尺度。完整 GA 的因子乘数按表 3 及 gradient/stable 代码采用 c；§3.4 和 Algorithm 1 的公式分母写作 γ。取舍会影响初始更新大小，解读与论文的数值差距时需保留这些区别。

## 6　区分训练顺序、校准样本和 SVD 的随机性

原作者 run_exp 先按原始训练行顺序选取 bsz × iters 条样本，默认 1×8，初始化长度上限 1024。新基线保留这一顺序，只在梯度类初始化使用校准集；config.json 保存真实 idx、顺序、类别文本和输入 token 长度。first-eight 选择器按原顺序取前八行，选样不消耗随机数。正式校准估计开启模型 dropout。随机低秩 SVD 使用 q=32、四次幂迭代；每层使用重新设定的生成器状态，种子为训练种子加层序号，作用域结束后恢复外部状态。init.json 按真实层名记录种子。与上游连续消耗同一随机流存在数值差别。

训练全排列由专用 CPU Generator 从训练种子生成，保存样本 ID 到 order.json；安装适配器后重新设置训练 RNG。分析入口比较同任务、同种子的顺序散列。这样，初始化工作量和 SVD 不会改变后续训练顺序。

## 7　记录收敛、恢复与首步对齐

训练输出每次更新的步号、累计样本、token 平均交叉熵、实际 LR。阶段计时在 CUDA 同步后读取；wall_s 自适配器初始化起算，含初始化、检查和已发生的验证，不含预先的数据准备与基座装载。训练和验证各有累计耗时，完整 JSON 另记重载完成时刻。比较图同时保留步数和墙钟横轴，每个点来自一次更新或一次实际验证。首尾缺测不作插值。

首步诊断使用同一干净基座的任务损失梯度 G。对单层 W_eff=W′+sBA，单位学习率的一阶 SGD 方向为 −s²[(GAᵀ)A+B(BᵀG)]。实际求导再计算 −s[(∂L/∂B)A+B(∂L/∂A)]，比较两式与 −G 的余弦。只对四个预选权重请求偏导，每个偏导等于全参数目标在对应权重上的分量。该线性化忽略二阶交叉项，AdamW 的矩估计、裁剪和 warmup 也不在此公式内。诊断对固定训练行 0–7 和 8–15 分别输出真实 ID，校准及测量均关闭 dropout。真实 T5 指标待后续本机运行。

每次正式运行先落盘配置，再保存初始因子、损失、预测与最终因子；通过重建补偿基座和固定输入重载检查后，才写完成清单。清单检查步数、尾批、全量验证 ID 数、由预测复算的 Accuracy、适配器容器及文件 SHA-256。残缺尝试按编号保留，可以重新从干净基座训练同一配置。
