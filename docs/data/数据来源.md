# 五任务数据来源

本项目从 nyu-mll/glue 的固定 revision `bcdcba79d07bc864c1c254ccfcedcce55bcc9a8c` 获取训练和验证 Parquet。下载地址由该 revision 和 `glue_files.json` 的 source 字段组成；本地只缩短了文件名。真实输入可以用 task、split 和整数 idx 从相应 Parquet 定位。课程材料使用各数据集原有许可；GLUE 数据卡把许可指向各原始来源，并列出引用信息。[固定版本数据卡与引用](https://huggingface.co/datasets/nyu-mll/glue/blob/bcdcba79d07bc864c1c254ccfcedcce55bcc9a8c/README.md)

| 任务 | 语料来源 |
|---|---|
| MNLI | Williams、Nangia、Bowman，Multi-Genre Natural Language Inference Corpus，2018 |
| SST-2 | Socher 等，Stanford Sentiment Treebank，2013 |
| CoLA | Warstadt、Singh、Bowman，Corpus of Linguistic Acceptability |
| QNLI | GLUE 根据 Rajpurkar 等的 SQuAD（2016）整理的问句和候选句分类任务 |
| MRPC | Dolan、Brockett，Microsoft Research Paraphrase Corpus，2005；本目录保留发行许可与来源说明 |

GLUE 的出处为 Wang 等，GLUE: A Multi-Task Benchmark and Analysis Platform for Natural Language Understanding，ICLR 2019。五任务实验保留训练集原始顺序用于选取校准样本，另存每个训练种子的样本排列。

`glue_files.json` 是下载前登记的预期值。`docs/validation/glue_files_actual.json` 是对本机 11 份文件的复核记录。每个文件都有预期和实测字节数、SHA-256、行数、字段、标签集合、唯一 ID 数及空值计数。可从根目录运行 `suite.py audit` 独立重算。
